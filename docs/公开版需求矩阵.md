# PokeFactory2 公开版需求矩阵

日期：2026-09-26。产品目标：在手机浏览器中完成《宝可梦对战工厂_项目设计框架_v1.md》描述的局内挑战与局外长期成长循环，并达到公开发布质量。本矩阵把玩家可得到的结果作为需求单位；文档中的“建议”“推荐”和代码中的占位状态均不自动等于已定稿、已实现。

状态口径：**模拟浏览器实玩**指 `docs/tasks/*/runtime.md` 记录的浏览器操作与指定视口结果，包含开发者 Win 辅助时须明说；**静态已验证**指源码、类型检查、测试或构建有证据，但尚无相应浏览器闭环；**仅隔离分支**指改动尚未合入本矩阵对应的主线版本；**缺失**表示当前玩家入口没有可操作的完整功能；**规则待定**表示设计框架尚不足以唯一确定玩家行为、数值或边界。模拟视口不等于实体手机，单条路径通过不等于公开版完整验收。
