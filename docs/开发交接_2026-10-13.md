## 当前有效的产品规则

下表按最近的用户决定和规则定稿整理。凡写“已定”仅代表**产品口径**，不代表已经在 `dev` 可玩。

| 范围 | 当前规则 |
| --- | --- |
| 工厂骨架 | 一条主线，六选三、每组七战。组内第 3、6 胜后先换怪或跳过，再开交换商店；第七胜直接结算。设置里的九世代是物种池单选。 |
| 商店 | 每次货架六件不同商品，标价并显示券余额；券足可兑换，不足则禁用。一次可买多件，也可不买离开；货架冻结，失败留节点重试，重复点击和刷新不能重复扣券或发货。无重抽、战间回复类消耗道具或扩容。 |
| 兑换券/BP | 每胜 +1 兑换券。商品稀有度 1/2/3 对应 1/2/3 券，最高 3 券。**每组七战成功后**，未用券按 1 券 = 1 BP 加到该组工厂单打 BP 和实际首领额外 BP 中，并受钱包 9999 上限约束；券随后清零，下一组重新积攒。中途败退剩券清零，不折 BP。旧“跨组保留到整局结束”已作废。 |
| 持有道具 | 首版候选九种：`scope_lens`、`quick_claw`、`kings_rock`、`choice_band`、`focus_band`、`heavy_duty_boots`、`loaded_dice`、`white_herb`、`mental_herb`。三名队员的本局装备基准互不重复；同一种整局最多一件，替换或丢弃后回到可兑换候选。替换下来的不进背包，下一战前按本局新基准返还。六件货架的数量保底依赖九种减去三名队员所持的三种。光粉不入首版。 |
| TM | 候选来源仍是固定 Rogue expansion 的 50 个 TM，普通 profile 学习判定；须完成招式 ID、固定正文、战斗效果及当前队伍能学且未学四项准入。**当前可上架 0/50**，不能用未验 TM 填货架。每台 TM 档位随准入再定。 |
| 进化道具 | 39 种：10 种进化石、连接线及 28 种其他专门道具；规则清单给出 91 条关系。只有队里有人确实可用时才进候选，稀有度 3，兑换后当场消耗。进化保留原四招与已装备持有道具；队员留在队中时，进化形态跨组、读档保持。王者之证首版只作为持有道具的处理是助手代决，用户可否决。 |
| 其他已定 | 首发初遇伙伴六选一且只在基地陪伴；旧版存档可拒绝或重置但须明确提示，同版本刷新和导入导出要可靠；公开网页以手机浏览器为目标。版权说明页已存在，发布素材/IP 权利仍须独立解决。 |

规则清单里保留了若干“可被用户否决”的助手代决：例如允许货架出现可装备但当前队伍没有触发场景的持有道具、九种保底池和部分进化道具边界。继续开发时应记录这些决定的依据与可能影响；若被用户修改，先重新计算货架覆盖和验收条件，不得让代码自行补商品。
