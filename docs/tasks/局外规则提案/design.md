# 局外规则提案：非繁殖永久收藏与初遇

日期：2026-10-13。designer 产物。用户最新决定覆盖本页上一稿：**Owned 只统计永久收藏，租借/换怪只记 Seen；不创建生蛋系统功能。** 以下明确分开已批准规则与尚未批准的来源候选，不据此自动赠予物种。

## 已批准：永久所有权口径

- Owned 只统计玩家正式获得的永久收藏。进入工厂三人队、胜后换怪及租借成员在本局进化，都不自动赋予永久所有权；租借和换怪只增加对应 Seen 记录。
- 工厂仍采用临时租借，永久收藏不直接进入工厂挑战。普通工厂战禁捕捉的现行边界不变。
- 玩家重复租借同一物种不重复增加 Owned，也不据此领取永久收藏奖励。合法获得的已有永久收藏不因败退减少。
- 初遇六选一、确认绑定当前存档、在基地陪伴的现有决定不变。用户选择“只统计永久收藏”的问题已明确包含初遇伙伴，因此已绑定伙伴登记 Owned 是本次批准来源；确认前浏览候选不能将六只都登记 Owned。
- 当前 `usePokeFactoryGame.ts` 会对 `playerTeam` 执行 `registerOwned`，这是需要修正的旧行为，不是永久获得规则。图鉴物种 ID 与真正获得对象的含义由任务计划落实；新版本同版刷新、重开和导入必须保持正确。

这项记录修复应沿全部写入口核对：租借队自动登记、捕捉回调、进化回调及导入恢复不能绕开永久来源条件。**租借成员进化仍是租借，不转为 Owned**；仅移除租借误记不能让进化回调再把它写回。普通工厂禁捕捉的既有规则保持，不藉核对回调重新开放捕捉。

## 已批准：移除生蛋系统

用户明确“不创建生蛋系统功能”。以下从目标、任务与验收中移除，**不是延期或可自动恢复的待办**：

- 双槽繁殖、相容度、亲代资格、后代遗传与物种规则。
- 产蛋、蛋队列、孵化位、孵化进度及离线计时。
- 依赖上述机制的加速、扩槽、香薰/繁殖消费商品，以及培育研究事件、相关每日/研究任务。
- 为让繁殖起步而赠一雄一雌伊布的上一稿候选。
- 上一稿的 7 次战斗产蛋 + 7 次孵化、现实时间替代及容量候选。

不再就这些废止候选提问，也不因为移除繁殖而自行新增经验养成或其他替代机制。旧 GDD 中“完整框架”的生蛋部分已经被本次明确决定覆盖。

删除基地中尚未实现的生蛋/培育占位入口属于取消功能的落实；不能保留一个暗示未来将开放此功能的禁用按钮或“待解锁”提示。此项不意味着删除非繁殖收藏或初遇陪伴入口。

## 非繁殖收藏来源：已批准与待批准

| 来源候选 | 推荐的玩家结果 | 当前状态与依据 |
| --- | --- | --- |
| 已绑定初遇伙伴 | 正式登记为永久收藏并记 Owned；确认前仅浏览候选不产生六只 Owned；永久记录绑定本档 | **2026-10-13 用户已批准**。确认永久收藏的问题明确包含初遇伙伴，用户随后只取消了生蛋来源 |
| 正式事件赠予 | 后续事件设计给出具体物种/形态、获得条件及一次性或可重复性，成功领取才记 Owned | **未批准具体名单、条件与配额**。依据 GDD §8.2 的事件赠予、§9 的来客/伙伴/收藏事件；不自行发伊布或其他保底物种 |
| 特殊首领或收藏里程碑 | 若后续事件树明确奖励永久个体，则以正式领取作为 Owned 来源；纯“见到”只 Seen | **未批准**。GDD §8.2 的首领解锁与 §9 的稀有遭遇不自动等于赠予，需在提案说明是访问内容还是永久获得 |

Seen 的精确展示边界、Forms 的计数粒度与首次登记奖励要继续定稿：推荐以玩家实际展示/遭遇为 Seen 来源，后台预取或图鉴加载不自动登记；Forms 展示实际见过和永久持有的区别，不能把所有资源文件都当已获得。它们是后续可审阅建议，不覆盖本页已批准的“租借/换怪只 Seen”。

**首个收藏修复任务边界**：本轮只落实已定 Owned 来源、已绑定初遇登记、租借/换怪/租借进化不增加 Owned，以及取消繁殖入口。Seen/Forms 尚未定的细则先保留现有行为并记录差距；不要把上一段的建议当获批的新来源或顺手重写整套图鉴计数。

## 当前代码与固定参考的界线

GDD §4.1/§4.4 支持工厂临时租借与普通战禁捕捉，§8/§9 支持非繁殖收藏和事件方向。Rogue 与 Emerald 的繁殖源码不再构成本项目待实现契约；它们保留在本地参考库即可，不需要迁入项目。

现有地区派遣代码及其奖励不自动变成获批的永久获得途径；先由 architect 核对真实行为，再由 designer 对齐事件表。未批准的资料占位、赠予或概率不构成产品决策。
