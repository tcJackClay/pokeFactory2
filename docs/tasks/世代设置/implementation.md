# 世代设置实施记录

- v10 只接受 `[1]` 至 `[9]` 的单元素世代值，默认 `[1]`。保存、读取和导入沿用同一规则；切换世代使旧租借及敌队预取失效。
- 设置页只显示一行“当前世代”按钮、名称和地区。点开后显示底部弹层，九个整行触摸目标使用原生互斥单选控件；选择一行后立即写入 `[id]` 并收起。进行中可继续的挑战禁用入口，保留原因提示。
- 弹层在 320×568、390×844、844×390 视口内限制高度，列表独立滚动；支持 Escape、遮罩和关闭键。打开时焦点进入当前选项，Tab 留在弹层，关闭后焦点回到入口。对话框、单选组和选中状态提供屏幕阅读器语义。
- 320×568 浏览器实测发现 `fieldset` 虽有溢出高度却无法改变 `scrollTop`。列表滚动层改为普通 `div` 并标注 `role="radiogroup"`，保留原生同名 radio；末项滚动需由 player 复测。
- 未改工厂物种池、预取键、战斗数据或存档结构。本轮 `npm run lint`、`npm test`（131 项通过）、`npm run build` 均通过；三种手机视口与刷新持久化交由 player 运行验收。
