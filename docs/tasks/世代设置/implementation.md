# 世代设置实施记录

- v10 只接受 `[1]` 至 `[9]` 的单元素世代值，默认 `[1]`。保存、读取和导入沿用同一规则；切换世代使旧租借及敌队预取失效。
- 设置页只显示一行“当前世代”按钮，地区用大字、世代用小字。底部弹层将九个互斥选项排成三列，地区为主标题、世代为副标题；英文窄屏卡片将副标题缩写为 `Gen 1`～`Gen 9`，单选控件仍提供完整朗读名。点选卡片立即写入 `[id]` 并收起。进行中可继续的挑战禁用入口，保留原因提示。
- 弹层在 320×568、390×844、844×390 视口内限制高度，列表独立滚动；支持 Escape、遮罩和关闭键。打开时焦点进入当前选项，Tab 留在弹层，关闭后焦点回到入口。对话框、单选组和选中状态提供屏幕阅读器语义。
- 320×568 浏览器实测发现 `fieldset` 虽有溢出高度却无法改变 `scrollTop`。列表滚动层改为普通 `div` 并标注 `role="radiogroup"`，保留原生同名 radio；旧版九行布局的末项滚动和刷新持久化已由 player 验收。三列布局需重新检查文字、触摸目标和横屏高度。
- 未改工厂物种池、预取键、战斗数据或存档结构。
