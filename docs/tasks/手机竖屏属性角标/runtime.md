# 320×568 战斗属性角标验收

2026-09-26 在隔离工作树的独立 Vite 端口 `4312`，以 Playwright Chromium 手机模拟器从新档正常选择伙伴、六选三并进入第一战，使用独立来源 `127.0.0.159`。没有访问用户原本的 `127.0.0.1:4300` 标签或存档。截图为实际游戏流程：[首战 320×568](evidence/stage1-ready-320.png)。

四张招式卡均显示属性文字与图标。浏览器量测每张卡为 `117×78` CSS 像素，属性角标在对应卡片内，四卡均未禁用且中心命中自身按钮；实际点按第一张招式卡成功。战斗操作面板为 `278×254`，右下边界 `299×551`，未超出 `320×568` 视口；页面 `scrollWidth=320`，没有横向溢出。浏览器页面异常为 0。其余三招仅验证了可命中的按钮区域，未逐招实际出招。
