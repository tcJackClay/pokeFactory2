# Snowscape 天气切片

## 技术计划

将 `snow` 加入战斗天气类型及存档校验，令 Snowscape 设置五回合雪天，同时保留 Hail 的独立来源与冰雹伤害。伤害计算仅在有效雪天下对冰属性承受物理招式的防御乘 1.5；雪天不产生回合末天气伤害。Blizzard、Slush Rush、Snow Cloak、Ice Body 与天气恢复招式沿用冰系天气共同判定，日光束在雪天仍减威力。天气由战斗级状态持有，换人不重置，开新战使用无天气初值。

验证顺序：先为纯结算加入实际伤害、HP、命中、速度、回合计时断言，再接 Snowscape 映射、战斗显示和存档白名单；最后执行类型检查、相关单测与构建。浏览器试玩由后续 player 完成。

## 实施结果

- Snowscape 的招式数据现在设置 `snow`；旧 Hail 继续设置 `hail`。控制器现有的 `getMoveWeather` 接线会将两者各设为五回合天气。再次使用任何天气招式会替换当前天气及剩余回合。
- 雪中的冰属性目标只在承受物理伤害时获得 1.5 倍防御；雪不造成回合末扣血。Ice Body 在雪中回血，Blizzard 在雪中必中，Slush Rush 与 Snow Cloak 在雪中生效。日光束和天气恢复招式按已有恶劣天气规则处理。旧冰雹伤害与旧冰雹相关特性仍保留。
- 战斗状态显示中英双语雪天名称。存档校验接受 `snow` 及其剩余回合。换人时天气仍为战斗级状态；工厂新战检查点初始化为 `none`、零回合。
- 新增伤害值、特殊伤害不变、非冰属性不变、旧冰雹伤害、雪无伤害、五回合到期、换人、Blizzard、Snow Cloak、Slush Rush、Ice Body、日光束、招式映射和存档读取断言。

类型检查 `npm run lint`、聚焦测试 92 项、全量测试 163 项、`npm run build` 均通过。生产构建仍报告现有大于 500 kB 的 chunk 提示。未运行浏览器或游戏，尚需 auditor 复审和 player 实战验收。当前战斗续玩采用开战检查点，刷新战中天气会回到开战状态；该行为与其他战斗级状态一致。
