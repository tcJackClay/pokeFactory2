# 敌队候选耗尽修复记录

敌队构队仍至多尝试 `3 × 25 = 75` 次。每一槽优先参考 set，再训练家物种提示，最后所选单世代全局池；参考或提示候选经过物种、世代、持有物、进化阶段与能力值检查后若均不可用，当前生成调用直接尝试下一来源。参考/提示成员详情处理失败时，后续有界尝试优先全局池。全局成员的持有物仍从原工厂许可池按既有槽位顺序选；原槽位持有物与已有成员冲突时顺序寻找该池内未使用的道具。物种与道具 ID 都归一去重，初始租借池和玩家队伍也同时封锁形态 ID 与基础物种 ID，防止敌队换用同物种的另一形态；索引无法证明所属世代的候选拒绝进入敌队。敌队详情使用完整招式资料，失败不能以部分配招或默认招式凑队。

诊断记录 stage、所选世代、训练家 ID、参考/提示/全局采样数、禁止物种/物种冲突/世代/道具/阶段/能力值/缺资料/详情错误分类、最终人数、尝试数与耗时。失败时输出结构化警告和含同一统计的错误；预取失败仅作警告，正式生成失败才在可操作页面显示重试提示。现有 `nextFactoryStage` 成功后才提交下一战，失败恢复原战后展示与阶段；六选三失败回原选择页。该静态边界沿用现有事务与回滚测试，本轮未操作浏览器。

受控随机的纯函数测试覆盖参考道具冲突、提示跨世代、全局组齐三名合法成员、全局也无解且恰好停在 75 次、道具连字符/下划线别名和能力值/阶段过滤。聚焦测试及既有战后展示回滚测试通过；全套 190 项、`npm run lint`、`npm run build` 通过。玩家浏览器仍需复测预取失败后正式生成成功、两次都失败时 stage/BP/券与检查点不变、重试成功，以及第 1/2/9 世代自然进第 2 战。
