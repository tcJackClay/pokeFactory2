# Tailwind 双方分侧状态

技术计划：用战斗级 `{ player, enemy }` 剩余回合数保存双方顺风，不附着于宝可梦或全场场地。招式成功时只设置使用者侧四回合；同侧仍有效时再次使用失败且不续时。行动排序先比较招式优先级，再将对应侧速度翻倍，并用现有戏法空间逻辑反转速度排序。每回合末分别减一，到零清除；换人沿用本侧剩余时间。工厂新战与其他新战均清零，保存快照严格校验这两个计时数。

先为纯状态施放、行动排序与回合末计时增加结果断言，再接入控制器、存档、界面状态和新战复位。静态检查通过后交 auditor 复审，浏览器实战留给 player。

实施结果：`tailwind` 载入为专用 `TAILWIND` 效果。玩家和对手各有独立计时，成功施放设为四回合；重复施放消耗原有出招流程的 PP 并给出失败消息，不延长时间。行动选择在优先级比较后按对应侧将有效速度乘二，再应用戏法空间的反序规则；回合末分别递减计时。战斗状态面板显示双方剩余回合。换人保留计时，新战、事件遭遇战、退出战斗及失败回滚均有明确复位或恢复路径。

存档快照保存双方计时，读取时只接受 0–4 的整数，异常值归零。当前工厂战斗仍使用开战检查点；战中刷新会回到开战状态，和现有天气、场地效果相同。本切片未开启 TM 奖励，也未改变商店或卡池。

验证：`npm run lint` 通过；聚焦 18 项测试通过；全量 `npm test` 168 项通过；`npm run build` 通过。构建仍有现存的大文件体积提示。未运行浏览器游戏，待 auditor 静态复审及 player 实战验收。
