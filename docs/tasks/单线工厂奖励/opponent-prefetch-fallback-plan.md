# 敌队候选耗尽修复计划

在现有最多 75 次的构队循环内，将参考、训练家提示、所选单世代全局候选依次过滤为可用集合。过滤条件包括物种/当前队伍重复、禁止物种、装备重复、世代、要求的进化阶段与能力值段；较高优先来源本轮无可用成员时，立即尝试下一来源，仍不增加总尝试上限。索引物种世代未知时拒绝，避免跨世代提示混入敌队。候选详情失败保留显式错误，不将不完整成员加入队伍。

构队记录 stage、选中世代、训练家、各来源采样数、分类拒绝数、已组成数量和耗时。预取失败只记诊断；正式生成失败保留原阶段与可恢复展示，并在六选三、战后换怪及基地继续入口显示可重试提示。用受控随机的纯函数测试覆盖参考道具冲突、提示跨世代、全局凑齐合法三人、全局也无解及 75 次上限。运行聚焦测试、全套测试、类型检查与构建，不运行游戏。
