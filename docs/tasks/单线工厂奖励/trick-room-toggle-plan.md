# 戏法空间关闭与场地计时计划

本项目 `applyFieldEffect` 的场地列表会在第二次戏法空间时移除 `trick_room`，计时列表却重新写成 5，状态与计时分离。固定 Rogue expansion 提交 `a6adfcf18d7eaf99c2803e4b0bc04eca7af2f014` 的 `HandleRoomMove` 对戏法空间、魔法空间、奇妙空间均按再次施放关闭并将计时置零；重力与妖精之锁已生效时则施放失败，不是切换关闭。地形招式维持本项目现有互相覆盖行为。

抽出纯场地转换函数，分别由 React 两个状态的函数式更新调用，确保连续施放按最新状态处理：三种 room 的第二次施放同时移除状态和计时；重力及妖精之锁重复施放不改变状态/剩余回合；地形清掉旧地形及计时，再以五回合设置新地形。倒计时继续使用现有 `resolveEndTurn`。

测试先后施放戏法空间与实际速度顺序反转及恢复、关闭后没有残留计时、五次回合末自然结束；另核对魔法/奇妙空间、重力/妖精之锁和地形覆盖。运行聚焦测试、全部测试、类型检查和构建；不启动游戏或启用 TM 奖励。
