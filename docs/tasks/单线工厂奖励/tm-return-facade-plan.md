# TM01 与 TM03 静态核验计划

从 SHA 校验通过的本地 PokeAPI 正文保存这两招的最小转换字段快照，核对 Rogue 固定提交中的 `EFFECT_RETURN`、`EFFECT_FACADE` 与项目覆盖表。实际走项目转换及伤害函数，以固定随机值测 Return 的 0/70/255 亲密度伤害单调性、最低伤害、换人状态和存档保留；追踪亲密度从租借物种 `base_happiness` 进入成员的路径。

Facade 分别比较健康、烧伤、中毒、剧毒、麻痹、睡眠和冰冻的伤害，确保只有 Rogue 指定状态翻倍，且烧伤不再施加普通物攻惩罚。若测试证实局部错误，仅修伤害条件并回归普通物攻。完成聚焦、全套测试、类型检查与构建；本轮不接奖励或浏览器。
