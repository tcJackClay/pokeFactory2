# 敌方单次行动门禁记录

毒菱浏览器记录提示一次玩家行动中敌方可能重复执行。静态调用链可复现触发条件：敌方回合 effect 依赖的回调会随 `resolvePreTurnStatus` 写入队伍而改变；消息播放标志尚未置位时，仍处于 `ENEMY`，effect 会再次启动自动行动。

为每个连续 `ENEMY` 阶段设置同步 claim；进入 `PLAYER` 或退出战斗时重置。claim 同时绑定战斗 epoch，避免新战仍处于 `ENEMY` 时沿用上一战的占用状态。队伍更新、消息开始／结束造成的重渲染均不能在同阶段再次启动。只有可行动且消息未播放时才 claim，避免加载中的重渲染误占用。

独立门禁测试证明同阶段连续触发只允许一次、阶段离开或战斗 epoch 更新后下一次可以执行。类型检查、全量测试与构建通过。此处只修行动入口；毒菱、顺风等实际浏览器重复行动现象仍需 player 在固定构建复测。敌方先手的整回合事务另有已确认的重复行动风险，不能以本门禁通过代替该路径验收。
