# 单线工厂交换商店设计

本文件记录玩家在工厂主线中看到的规则。以用户最新决定和《docs/公开版规则定稿.md》为准；商店道具与进化映射的详细名单见《docs/tasks/扩池规则/decisions.md》和《docs/tasks/扩池规则/evolution-items.generated.md》。参考 Battle Factory 的七战、换怪与 BP 见《docs/对战工厂原型核对.md》；交换商店和兑换券是本项目扩展，不能把 Rogue 的动态商店库存、价格或解锁条件直接搬进来。

## 玩家流程

1. 首版只有一条工厂挑战主线，没有 Classic / Rogue 模式选择。每组七战，开局六选三。每组第 1～6 胜后可从刚击败的敌队换一只或跳过；第 7 胜直接组结算。
2. 每组第 3、6 胜后，先完成换怪或跳过，再打开交换商店。商店加载失败时留在节点并重试，不跳到下一战。货架默认摆六件互不重复的合格商品；首次摆出后冻结，刷新、重开、同版本导入不重抽。合格商品不足时显示不足并留在节点，不以重复、未验收商品或空位凑数。
3. 货架上的每件商品标注券价。券够才能兑换；玩家可在一次开店中兑换多件，也可不买直接离开。同一件商品只可兑换成功一次，连续点击或导入不得重复扣券、重复交货。商店不设重抽。
4. 每胜获得一张兑换券，进入本组第 3 胜商店时有三张，进入第 6 胜商店时余额由本组此前消费决定。券不能在基地直接当 BP 花。第 7 胜完成整组时，未用券按一券等于一 BP 并入组末 BP，受钱包 9999 上限约束；折算后券清零，下组从零开始。组内败退时剩券清零，不折算，也不发本组 BP。
5. 整组获胜另按参考工厂单打表发 BP：前两组各三 BP，之后按原表；实际击败工厂首领额外十 BP。前六胜不向基地钱包发 BP。

## 商品与装备

商店只卖战斗持有道具、通过准入的技能机，以及当前队伍能使用的进化道具；不卖战间回复道具、新宝可梦、队伍扩容许可或力量强化、防御强化一类战斗消耗道具。

商品分三档：稀有度一为一券，稀有度二为二券，稀有度三为三券。已定持有道具九种：焦点镜 `scope_lens`、先制之爪 `quick_claw`、王者之证 `kings_rock`、讲究头带 `choice_band`、气势头带 `focus_band`、厚底靴 `heavy_duty_boots`、机变骰子 `loaded_dice`、白色香草 `white_herb`、心灵香草 `mental_herb`。讲究头带三券；焦点镜、王者之证、气势头带、机变骰子、心灵香草二券；先制之爪、厚底靴、白色香草一券。全部已定进化道具三券。技能机各自的档位要在逐项通过上架验收时确定，当前没有已准入的技能机。

持有道具由玩家指定一名当前租借队员装备；该队员已有道具时，先确认替换，旧物不入背包。新装备成为该成员本次挑战此后各战的返还基准。战斗结束后 HP、PP、异常与临时状态恢复；战中消耗或被拍落的当前持有道具在结果和换怪时仍如实显示，下一战开战前才按返还基准装回。三名队员的返还基准不得重复。同一种持有道具整局最多一件：由队员持有或留在可兑换名单；被替换或丢弃后重新进入名单，不记“曾经拿过”的账。可上架的条件性道具必须如实说明适用场景，不能宣称当前队伍必定用得上。

进化道具包括十种进化石、代替通讯交换的连接线 `linking_cord` 和二十八种其他专门道具，合计三十九种、对应九十一条参考进化关系。只有当前队伍有符合条件的成员时，对应道具才进入随机货架候选；商品出现并不保证每次开店都能买到。兑换成功后当场选符合条件的队员进化，道具消耗且不返回货架；进化后保留该队员原有四招，形态随该队员在本次挑战中持续，跨七战组也不回退。王者之证在首版只按持有道具出售，不兼作蚊香君、呆呆兽的进化道具；这是可由用户否决的代决。

设置中九选一的世代只控制租借和敌队的物种池。技能机统一参考 Pokabbie/pokeemerald-rogue `expansion` 固定提交 `a6adfcf18d7eaf99c2803e4b0bc04eca7af2f014` 的五十个 TM，按普通 profile 中 `TutorMoves ∪ LevelUpMoves` 判断是否可学；动态 TR 或历代机器招式并集不进入池。每台技能机还须确认项目招式 ID、固定正文、战斗效果，以及当前队员可学且尚未学过，才可上架。来源抽取与身份映射已有静态记录，逐招上架验收仍为零。

## 当前实现与证据边界

`dev` 已合入七种持有道具的四件随机候选、候选冻结、一次领取、换装后唯一性与存档路径，旧规则下的十七项浏览器实玩见 `docs/tasks/四卡生成/`。它仍是“免费四选一”：无六件商店界面、标价、扣券、多件购买、组末余券折算、九道具完整候选或三十九种进化道具流程。白色香草的战斗触发仍需接入；现有进化流程会重新随机四招，与现行保留四招规则相反。隔离工作树 `codex/reward-shop` 有商店第一阶段提交及未提交改动，只有通过审计、当前版本实玩和合并后才算 `dev` 可用。旧四卡截图不证明新版商店。

每胜加一券、战后恢复、组末原型 BP 有局部浏览器证据；跨组首领长局使用过 DEV Win。固定 TM 来源和物种/形态身份映射是静态证据，不能当招式效果与领取实玩。模拟手机视口与实体手机、生产环境各自验收，不能互相替代。

## 历史规则

早期“每组第 3、6 胜四选一免费领一张”“商品只含持有道具和 TM”“兑换券跨组保留到整次挑战结束”“首版不开放进化”“五件或七件持有道具足以覆盖货架”均已被后续交换商店决定覆盖。原四卡实现及测试可作为代码基线，不能充当当前产品验收条件。

## 仍待用户定夺

- 基地 BP 商店的商品、价格、购买次数及效果，与本局交换商店分开定稿。
- 每台 TM 的实际效果验收与上架档位；当前不能把五十个来源 TM 当作已可出售的商品。
- 十五种属性强化持有道具是否纳入首版及其 1.2 倍调整、气势头带触发后是否消耗、光粉是否排除，仍在 `docs/tasks/扩池规则/decisions.md` 记录为未获最终决定的扩展取舍。
- 王者之证同时作为持有道具与进化道具的商品用途安排；首版只作持有道具是可被用户否决的代决。九种持有道具、条件性商品、进化道具统一三券及进化保留四招等代决也允许用户否决，否决后须重算六件货架覆盖并修订规则。
