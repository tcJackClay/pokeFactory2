# TM24 毒菱实施记录

基线为 `origin/dev` 的 `760bbce`，规则按本目录计划所列固定 Rogue 源码。此提交只实现战斗效果与场地显示，不启用奖励卡或改变招式机发放。

- `toxic-spikes` 映射为对方场地效果。施放按双方独立的 0→1→2 层推进，第三次失败且不改层数。
- 统一入场管线先结算隐形岩伤害与濒死，再按接地判定吸收或附加中毒。接地毒属性含厚底靴会清除该侧毒菱；非毒属性厚底靴不会中毒。飞行、飘浮、`eelevate` 不接地，重力使其接地。已有异常、钢属性、免疫与神秘守护、薄雾场地阻止附加中毒；魔法防守不阻止附加中毒。`pastel-veil` 在入场判定中显式阻止中毒。
- 入场结果包含新队员、新场地及有序事件；吸收时立即同步场地 ref 与 React state，后续连环补位读取清除后的层数。双方场地面板显示层数。稳定战斗快照沿用已有双方场地与成员异常字段。
- 结果测试覆盖施放封顶、双方隔离、岩石与中毒顺序、濒死、接地及重力、毒属性吸收、厚底靴、魔法防守、状态免疫和连续入场；存档测试覆盖双方层数、剧毒计数恢复及非法层数拒绝。

仍需固定构建的浏览器运行验收：竖屏与横屏的玩家施放、主动换人、双方濒死补位、刷新恢复、场地显示和日志顺序。本切片没有运行游戏，静态测试不能替代这些观察。
