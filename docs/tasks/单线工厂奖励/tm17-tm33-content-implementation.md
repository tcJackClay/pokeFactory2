# TM50 固定内容种子实施记录

本切片只修改隔离工作树的内容准备代码。固定清单包含 Rogue TM01–TM50 的 50 个 `move/{name}` 键，来源提交为 `a6adfcf18d7eaf99c2803e4b0bc04eca7af2f014`，抽取输入摘要为 `353a1226dae0a7601cef5a3613572d35d0cf9a780299426a9cadc6a36e21bb9e`，有序映射摘要为 `20d76b0c244a45edd20ee5d789c64ce467a2efe2278e2e4c193037368f8953dc`。清单只保存 TM 编号与招式键，没有提交 Rogue 物种兼容矩阵。加载时校验来源、顺序、唯一性、完整性和摘要；TM17 固定为 `move/freeze-dry`，TM33 固定为 `move/quiver-dance`。

`-factory` 与 `-factory-generation=1..9` 均合并固定 50 键，并将来源写入 PokeAPI 版本 manifest。`-factory-sample` 仍只有指定物种，`-full` 和普通模式仍按原种子。准备时检查每个固定键都实际获得正文，正文至少有有效 `id`、正确 `name`、正数 `pp`、`type`、`damage_class`、`target`、`meta` 和 `stat_changes`。缺键、坏正文、条目/字节/期限超限均不得发布版本，失败暂存由原有清理路径移除。工厂模式仍只准备、不激活；没有运行真实 PokeAPI 同步或改动共享 `var`。
