# 隐形岩与统一入场结算

技术计划：战斗级状态按玩家和对手两侧分别保存隐形岩，预留毒菱层数字段；撒岩只把对方侧设为一层，重复施放失败。纯 `resolveEntryHazards` 使用岩属性倍率结算最大 HP 的 1/8，向下取整且非免疫至少扣 1 点；厚底靴与魔法防守阻止岩石间接伤害。控制器的主动换人、敌方主动换人及双方击倒补位都通过同一入场入口，未来 pivot 直接复用；因陷阱倒下的成员不得继续行动，也不得重复触发。场地陷阱在换人后保持，开新战清空，存档校验双方状态并在状态面板显示。先写纯规则结果测试，再接各入口及流程测试，最后执行静态门禁；不运行游戏或启用 TM 奖励。

实施结果：`BattleHazards` 以双方独立状态保存，毒菱层数仅为后续扩展预留，不触发任何结算。TM35 的 `stealth-rock` 招式映射到专用效果；重复施放不刷新、不叠加。`resolveEntryHazards` 根据入场成员当前属性计算岩属性倍率，再扣除最大 HP 的 1/8，至少 1 点且不会扣出负 HP。玩家与敌方的主动换人、击倒后补位均调用控制器中的同一入场入口；入场倒下时提示濒死并继续寻找后备。双方陷阱随战斗快照保存，失败恢复原展示，下一场战斗的原子启动检查点与各新战入口清空陷阱。状态面板标出陷阱位于哪一侧。

道具与特性边界：当前战斗元数据中的魔法防守免疫隐形岩伤害；新增厚底靴效果元数据并在入场伤害中识别，但未修改工厂持有物配置，也未投放厚底靴。未实现其他场地陷阱、清除场地陷阱的招式或 pivot 招式；后续这些功能可调用同一纯入场结算函数。属性倍率使用成员入场时的当前属性。TM 奖励卡与可获得范围未改动。

验证：新增规则结果断言覆盖双方定向、重复施放、四倍/半倍/四分之一倍岩伤害、最低伤害、入场击倒、厚底靴和魔法防守；另有招式效果映射、战斗快照保存/损坏校验、新战清空测试。`npm test` 186 项通过，`npm run lint` 通过，`npm run build` 通过。未启动游戏或浏览器，因此实际画面、点击和完整实战路径仍需 player 验收。
