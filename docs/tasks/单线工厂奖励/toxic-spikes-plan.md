# TM24 毒菱实施与验收计划

基线：主线 `20d70ec`；规则依据为本地固定的 Pokabbie/pokeemerald-rogue `expansion` 源码 `a6adfcf18d7eaf99c2803e4b0bc04eca7af2f014`。这是 TM24 的战斗效果切片，不能以招式能加载、能发卡或出现通用伤害代替结算验收。

## 已有入口与原型规则

- `src/types.ts` 的双方场地已经各有 `toxicSpikesLayers: 0 | 1 | 2`；`src/features/game/battle/engine/resolveEntryHazards.ts` 已处理隐形岩，但只返回伤害和濒死，不返回可变的场地与状态事件。
- `src/features/game/data/battle/moveEffectTable.ts` 只覆写了隐形岩；`src/features/game/hooks/useBattleController.ts` 的出招分支只识别 `STEALTH_ROCK`。玩家主动换人、玩家濒死后手动补位、敌方濒死后自动补位及敌方换人都经过 `enterBattlefield`，应在这个共同入口处理毒菱。`BattleStatusPanel.tsx` 只显示隐形岩。
- 原型 `src/battle_script_commands.c` 的 `Cmd_settoxicspikes`（约 14332 行）把目标侧由 0 层升至 1、2 层；已达 2 层再次使用失败。入场脚本（约 7100–7144 行）先结算隐形岩，再结算毒菱；隐形岩使入场者濒死时，不再让它获得中毒。
- 原型中只有接地者触发毒菱。接地毒属性先清除该侧全部毒菱，判定早于厚底靴；故穿靴的接地毒属性也吸收。其他接地者若无厚底靴、已有主要异常、钢属性、免疫中毒能力、该侧神秘守护或薄雾场地，则 1 层普通中毒、2 层剧毒。魔法防守只免疫隐形岩及中毒间接伤害，**不阻止毒菱附加中毒**。原型还检查 Pastel Veil；若本项目可租借该能力，需查明本地能力表并实现等效拦截，不能默认为可中毒。

## 最小实现顺序

1. 在 `moveEffectTable.ts` 给 `toxic-spikes` 标准化 `effectId: 'TOXIC_SPIKES'`、目标对方场地；在 `resolveEntryHazards.ts` 增加纯函数 `resolveToxicSpikesUse`，按施招方反侧设置层数，封顶 2，第三次明确失败且不改状态。`useBattleController.ts` 的招式分支仿照隐形岩更新 `hazardsRef` 与 React state，打印本地化成功、叠层、失败反馈。敌方出招走同一入口。
2. 扩展 `resolveEntryHazards` 输入以取得当前 `fieldState`，统一本项目现有的接地语义：重力接地，否则飞行属性、飘浮及 `eelevate` 不接地。返回新宝可梦、新 `hazards` 和按顺序排列的事件：隐形岩伤害及可能濒死 → 接地毒属性吸收 → 其余接地者的中毒判定。使用 `getNonVolatileStatusId` 防覆盖已有异常，使用 `setNonVolatileStatus` 写入 `poison` 或 `bad_poison` 并确认剧毒计数初值；毒、钢属性和中毒免疫能力检查要与 `battleResolution.ts` 对齐。厚底靴跳过附加中毒，但不可跳过毒属性吸收；魔法防守不可用于毒菱免疫。神秘守护、薄雾场地及本项目已经支持的相关能力应复用同一判定口径，必要时先抽出共享纯函数，避免把伤害招式判定直接挪用到入场效果。
3. `enterBattlefield` 在吸收后立即同步写入 `hazardsRef.current` 和 `setHazards`，确保同一次连续敌方补位看见已清除的场地；`reportEntryHazards` 逐条报告伤害、濒死、吸收与中毒。当前函数在 `damage <= 0` 时直接返回，必须调整。主动换人与双方濒死补位继续调用唯一入口；每次只对实际新入场成员执行一次。`BattleStatusPanel.tsx` 显示双方毒菱 1/2 层，清除后立即消失。新战斗仍由现有 `createEmptyBattleHazards` 重置。
4. `saveManager.ts` 已将 `hazards` 纳入 `BattleResumeSnapshot`，并对层数做 0–2 校验；`usePokeFactoryGame.ts` 有稳定玩家回合快照。此切片不需新字段或旧档迁移，但需检查附加异常、吸收后的新层数与快照在同一稳定点写入，不能由旧闭包覆盖。运行中出招动画或连环补位不作为可恢复检查点；恢复到最近已提交的稳定回合并保证不重复施加毒菱。

## 结果断言

| 情景 | 必须观察到的结果 |
| --- | --- |
| 双方分别施放 1、2、3 次 | 只累加在对方一侧：0→1→2，第三次失败；另一侧数值不变，面板显示正确。 |
| 隐形岩与毒菱同侧 | 先扣隐形岩 HP，再赋予异常；若扣至 0 HP，则报告濒死且不赋予中毒。 |
| 飞行／飘浮／重力 | 不接地者不吸收、不中毒；重力下按接地重新判定。 |
| 接地毒属性，含穿厚底靴 | 清除所在侧两层毒菱、自己不中毒；对侧毒菱不变；随后入场者不再中毒。 |
| 接地钢属性、已有烧伤等主要异常、免疫中毒能力 | 毒菱保留，目标原状态不变且不新增中毒。 |
| 一般接地成员、厚底靴、魔法防守 | 1 层普通中毒、2 层剧毒；厚底靴不受毒菱影响；魔法防守仍获得中毒，但中毒的间接 HP 损失由原有结算阻止。 |
| 神秘守护、薄雾场地、Pastel Veil（若可出现） | 与固定原型的阻挡条件一致；无法覆盖的能力须暴露为未通过项。 |
| 玩家主动换人、玩家濒死补位、敌方主动换人、敌方濒死连环补位 | 四条路径仅在入场时触发一次；吸收后下一人看到零层；不因重复渲染或连环补位重复施加。 |
| 刷新与新战斗 | 稳定回合刷新后双方层数、成员异常、场地显示一致；吸收后刷新不复活毒菱；新战斗均为零层；损坏层数（负数、3、小数）走现有损坏存档保护。 |
