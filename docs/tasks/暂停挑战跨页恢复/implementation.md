# 暂停挑战跨页恢复实施记录

第七胜回基地时的 READY/BASE 检查点现在独立于浏览页保留。自动保存经过设置、版权、图鉴和事件页时继续写入同一快照；`challengePaused` 只在有效 BASE 快照存在时为真，刷新恢复不再单凭暂停标志判断。下一组战斗生成期间继续保留旧检查点，直到新战斗形成稳定快照。

可续挑战期间，事件页仍可查看地区与派遣计时，但派遣、领取、选择、推荐、清除和开发 Mock 均被禁用。hook 的入口及异步请求完成后的写入点也检查可续状态，防止旧点击或等待中的请求改动共享队伍、背包及战斗状态。

基地新增“结束当前连胜”及二次确认。结束操作先同步保存钱包和空恢复快照，成功后清空内存中的继续资格与预取敌人；保存失败保留原挑战并提示重试。已入账 BP 与首领徽记保留，不产生下一组结算。之后事件操作恢复可用。

验证：类型检查通过；117 项测试通过，包含结束操作在保存失败时保持可恢复、重试后清除资格且保留 BP；生产构建通过。跨页、触控与刷新行为需由 player 在浏览器中复验。
