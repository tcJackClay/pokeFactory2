# 图鉴招式名称本地化运行验收

2026-09-26，使用独立 Chrome 浏览器上下文、`127.0.0.21:4300` 和 390×844 视口验收。样本由同版本隔离存档导入，先返回基地再首次打开图鉴；随后在设置切换英文并重新打开图鉴。没有读取或清除用户 `127.0.0.1` 存档。本记录验证图鉴展示，不代表全新存档的完整游戏流程。

| --- | --- |

| 中文首次打开约 10.03 秒 | 仍可见上述繁体字名称。 |
