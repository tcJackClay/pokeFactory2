## Feature Spec

### F1：基地手机排版

进入基地时当前标题、状态、已绑定伙伴、开始/继续挑战与四入口都应可读可点。修复英文320宽时Standby与标题重叠、伙伴标签挤近Start Run的问题；保留当前视觉风格、实际伙伴素材和现有行为。正常内容可纵向滚动，不能靠裁切文字或遮盖按钮修复。中文、繁中和英文、横屏/竖屏与长名称均不互相遮挡。

### F2：事件已选队员摘要

进入事件页后，已选队员摘要应自行加载真实名称/类型与当前资格，不要求先打开选择器。数据尚未返回时明确显示加载状态，不把未知信息称为“未选择”或“属性不匹配”；真实无选择、真实不匹配与加载失败应可区分。失败可重试，不清除玩家已选队员；打开选择器与领取仍沿用原校验。队员或存档改变后只展示当前选择，迟到响应不能覆盖新选择。

### F3：本任务页面语言与玩家文案

基地和事件页自有的按钮、标题、等待/加载/失败说明随现有语言设置一致；事件名称、描述及物种名复用已有本地化数据，发现缺失先报告来源。移除面向玩家的Mock/内部实现调试说明，保留玩家决定操作所需的真实条件、时间与消耗信息。不得把尚缺完整恢复或自然球来源包装成已完成能力；不新增商品、数值或发奖承诺。

调研确认的本片边界：地区/地点配置仅有简中、伙伴配置缺繁中，`lastResult`/`popup.message`来自上游已经拼好的中文且缺完整结构化结果。本片不靠文本猜译、不删除训练数值或奖励信息，不扩大上游Hook写入所有权。这些缺失逐项登记为后续结构化本地化任务；F3本次通过只涵盖页面自有文案，不称整页完整本地化。页面自身Mock说明要清理，上游结果仍有相关泄漏时如实保留缺口。

## Edge Cases

- E1：320×568、390×844、844×390三种触控模拟尺寸，中英必测、繁中抽查长文本；内容自适应，页面无横向溢出，所测控件触达且不重叠。
- E2：详情冷加载、请求失败重试、打开/关闭选择器、切换当前选择、页面离开后迟到响应均保持显示属于当前上下文。不得改变领取互斥门闩、概率、存档或支付顺序。
- E3：新档伙伴选择及自然进入基地、已有有效派遣选择、可续工厂时禁用事件操作各自验证。受控存档、拦截延迟/失败必须记录；模拟浏览器不等于实体手机。
