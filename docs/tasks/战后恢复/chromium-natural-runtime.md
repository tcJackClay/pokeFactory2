# 隔离手机模拟浏览器自然道具试玩

2026-09-26 在主目录提交 `fe4e891`、本地预览 `4300`/代理 `3001`，以**隔离 Playwright Chromium 手机模拟器**访问 `127.0.0.158:4300` 建立新 v13 存档。Codex 侧栏浏览器当时不可用，具体阻断见 [侧栏记录](codex-browser-runtime.md)。本次没有访问或修改用户原有 `127.0.0.1` 标签/存档，没有改实现代码，也没有使用 DEV Win；仅在设置中开启开发按钮以供观察，该按钮未用于战斗结果。

正常 UI 选初遇伙伴、第 1 代六选三、训练家对白继续后，第 1 战可操作。选择的腕力原配 `white_herb`，当前仍持有 `white_herb`；另两只为 `leftovers` 与 `choice_band`。腕力四招为 `rock-slide`、`snore`、`mimic`、`karate-chop`，没有自降能力招式。首战敌方前两只没有拍落或降能力招式，第三只有 `knock-off`，因此单个有界首战样本无法稳定触发白色香草消耗。实际点击一次“岩崩”，战斗日志显示腕力出招、对手架起光墙；道具未消耗。[原始状态、动作、异常](evidence/chromium-natural/results.json)、[390×844 首战](evidence/chromium-natural/stage1-ready-390.png)、[实际回合](evidence/chromium-natural/after-one-real-move.png)。浏览器无页面异常或 HTTP 400 及以上响应。

390×844 和 320×568 均无页面横向溢出，战斗菜单与四招按钮可见。320×568 的四招卡片**没有任何属性文字或属性图标**；仅卡片背景颜色区分属性，无法直接读出招式属性，属于小屏可读性缺口。[320×568 截图](evidence/chromium-natural/stage1-ready-320.png)。设置中开启的 DEV 按钮在两种视口都遮住左上 BP 指示；此按钮只出现在开发模式，本轮不能把它当成公开版默认界面的遮挡。

本轮没有道具消耗，也没有胜负结果页，故“消耗后结果/换怪仍为空、下一场开战前返还、刷新保持”仍**未通过实际浏览器验证**。本次只证明可消耗道具可自然租入并用于首战，不能把原配字段存在视为返还行为通过。
