# 战后恢复计划

目标：对战工厂每场结算成功后，队伍立即以满 HP、满 PP、无异常状态进入后续页面；下一战无需恢复型补给道具。恢复仅作用于对战工厂，不改变 BP、奖励卡和商店。

现状：`useFactoryFlow.healAllPokemon` 仅回满 HP，且只在进入下一战时调用；交换后 `performSwap` 生成的队伍会覆盖前一次恢复。`useBattleController.resolveBattleResult` 在结算成功后切到 `ROUND_RESULT`，可在此处恢复队伍，使结果页和保存快照得到恢复状态。战斗临时状态还包括挥发状态、能力阶级、招式锁定、连续使用计数和特殊形态。

实施：提取纯函数恢复单只及整队宝可梦；成功结算时立即调用，并在旧档继续下一战、奖励页进入下一战及交换敌方宝可梦的路径复用。以招式 `maxPp` 优先、`pp` 次之回满当前 PP；保留物种、培养数据、持有物及招式 ID。重算特殊形态造成的临时 HP/能力值，恢复原属性。测试覆盖战后、换怪、变身和无最大 PP 字段，并运行类型检查、测试与构建。浏览器实玩由后续验收执行。
