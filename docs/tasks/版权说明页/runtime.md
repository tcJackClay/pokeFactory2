# 版权说明页运行验收

日期：2026-09-26。基线提交 `13a7a85`，测试时工作树含版权页、钱包和横屏的未提交修改，因此本记录对应当时的运行工作树，不能单独归于基线提交。前端为本地 Vite `4300`，Go 服务 `3001`。使用独立 Chrome 测试上下文访问 `http://127.0.0.3:4300/`，未使用或清空用户 `127.0.0.1` 的存档。Codex 侧边浏览器在本次子任务中不可用，改用独立浏览器上下文实测。

## 操作与结果

每组视口从新存档基地进入「设置 → 版权与素材来源 → 返回设置 → 基地」，并在设置中切换英文后重复版权页阅读与返回。正文滚动到末尾，检查页宽、返回按钮、来源外链及前后存档。截图和结构化状态保存在 [evidence](evidence/)；完整链接及尺寸记录见 [runtime.json](evidence/runtime.json)。

| 视口 | 中文滚动距离 | 英文滚动距离 | 结果 |
| --- | ---: | ---: | --- |
| 320×568 | 768 px | 1001 px | 标题在窄屏换行；正文可读、可滚动到底，返回设置始终可见，页面无横向溢出。 |
| 390×844 | 277 px | 505 px | 中英文正文可滚动到底，返回设置始终可见，页面无横向溢出。 |
| 844×390 | 438 px | 483 px | 横屏中英文标题与返回按钮同屏，正文可滚动到底，页面无横向溢出。 |

三个视口均检查了 10 个来源链接。浏览器中的 `href` 分别指向宝可梦官方内容使用说明、PokéAPI 项目与许可、PokeAPI/sprites 项目与许可、PokeAPI/cries、52Poké 属性页面、PokeRogue Assets 项目与来源许可标记、PokeRogue 项目；所有链接均为新标签打开并带 `noopener noreferrer`。在 `390×844` 实际点击官方说明链接，新标签地址与页面声明的官方地址一致。其外部网站内容和最终响应未纳入本轮验收。

返回设置和基地后，存档中的 `progress`、`factory`、`collection`、`events` 对象与进入前一致；`320×568`、`390×844` 还在刷新后复核了上述对象。切换英文使设置中的语言值变化，属于预期设置变更。`844×390` 返回基地后也验证上述四项未变。

本轮最初一次 `844×390` 测试撞上并行代码热更新，出现 React Hook 顺序错误和白屏；代码稳定后重新打开独立上下文并完整复测，中英文导航、滚动、截图及存档检查均通过。稳定复测没有页面脚本异常。`320×568` 另记录到 `/favicon.ico` 返回 404 的浏览器控制台错误，未影响版权页操作，仍需作为资源问题单独处理。
