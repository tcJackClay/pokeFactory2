# 版权说明页需求

## 玩家目标

玩家可以从基地的“设置”打开独立的版权与素材来源页面，了解项目的非商业性质、与相关权利人的关系，以及当前使用的数据、图像、声音和场地素材的来源；阅读后返回设置，不丢失当前进度。

## 来源与边界

- 用户于 2026-09-26 要求为非商业网页项目增加版权说明页面。
- 说明页面只陈述可核对的来源和权利归属，不以非商业性质、署名或免责声明宣称已获得宝可梦 IP 或第三方素材的公开使用许可。
- 公开发布的素材权利核查仍是单独的发布门槛；本任务不改变玩法、存档结构或服务端接口。

## 完成条件

1. 基地 → 设置 → 版权与素材来源 → 设置 → 基地的导航可用，返回后原有存档与进行中的挑战不变。
2. 中文和英文界面都有准确、可读的说明，来源链接指向对应项目或许可页面，并以安全方式打开。
3. 页面在 320×568、390×844、844×390 视口可滚动、可阅读，返回入口始终可操作。
4. 静态检查通过，并在实际运行的前端完成手机尺寸模拟试玩；记录视口、操作、画面和错误。

实施与验证细节见 [plan.md](plan.md)。
