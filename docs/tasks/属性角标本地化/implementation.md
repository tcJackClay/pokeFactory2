# 属性角标本地化实施记录

英文新档实玩记录 `docs/tasks/战斗状态标签/english-fresh-runtime.md` 显示，设置已切为英文且战斗日志为英文，但战斗 HP 卡和招式卡的属性角标仍是中文。根因是共用的 `TypeBadge` 固定读取 `TYPE_ZH`，没有接收当前语言。

`GameView` 将现有 `currentLanguage` 传入属性角标语言上下文，`TypeBadge` 据此输出中文或首字母大写的英文属性名。战斗双方 HP 卡、招式卡、租借、交换、宝可梦详情、图鉴及奖励页均复用该角标，因此一处接线覆盖这些页面。属性 ID、配色、图标及战斗规则未改。

验证：`npm run lint` 通过；`npm test` 142 项通过，其中新增测试遍历全部 18 个已有属性并检查中英文标签和复合 ID 兜底；`npm run build` 通过。未运行浏览器，待实玩复核英文新档的 HP 卡、招式卡及其他复用页面。
