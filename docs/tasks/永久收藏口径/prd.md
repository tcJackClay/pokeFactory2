# PRD：永久收藏口径与取消生蛋入口

orchestrator 拥有。依据：2026-10-13 用户“只统计永久收藏”“不创建生蛋系统功能”，`docs/公开版规则定稿.md` 末节及 `docs/tasks/局外规则提案/design.md`。本任务提前落实已明确且独立于战斗控制器的 Stage 6 切片，不代表基地全部完成。

## 任务约束

- 工作树 `D:/Games/pokeFactory2-worktrees/permanent-collection`，分支 `codex/permanent-collection`，起点 `0fd19eb`。
- 所有权：图鉴登记、初遇确认到永久记录、基地取消功能入口和相应存档验证；不改战斗控制器/命中引擎。若需写共享存档结构，先报告具体改动面并取得 orchestrator 排期。
- 不创建生蛋、孵化或替代养成；不自行新增赠予、事件奖励、BP 商品或图鉴奖励。不要求旧档兼容，但同版本刷新/重开/导入须一致。

## 功能规格

### F1 初遇伙伴

六只初遇候选只供选择，浏览/改选不能把六只都记为已拥有。确认绑定成功后只有已选伙伴登记永久 Owned 与对应 Seen，重复打开基地/图鉴、刷新或重开不重复增长。伙伴仍绑定本存档，只在基地陪伴，不进入工厂租借池；不能因永久登记额外发 BP 或改变亲密度。来源：规则定稿最新第4条。

### F2 工厂租借只记录见过

工厂租借、六选三、胜后换怪及对租借成员使用进化道具都不产生永久 Owned；它们按既有遭遇记录维持 Seen。选择租借队不把初遇或既有永久记录清掉，败退不撤销已有永久收藏。必须沿全部登记入口核对，不能只修正一个列表渲染掩盖存档污染。来源：最新永久收藏口径及局外提案。

### F3 图鉴与恢复

“已拥有”筛选和数量反映永久记录；“见过”仍能查看租借与遭遇。重复物种不增加已拥有物种数量。新的合法版本刷新、重开、导出再导入后结果一致；写入失败不能显示成功并留下不一致记录。用户不要求旧版存档兼容，旧档可按既有提示拒绝或重置，不能把旧租借 Owned 无依据迁移成永久收藏。具体版本或可追溯记录策略由 architect 调研提出，不由本PRD指定字段。

2026-10-13 用户进一步选择“保留现有获得方式，补成永久收藏”：保留当前地区派遣的加入宝可梦与可捕捉战斗，成功加入/捕捉所得登记为永久收藏。维持现有获取方式、消耗与概率；失败、取消、重复点击和重复处理同一次成功不得产生额外永久记录。不能在完成派遣后改成空领取或封锁入口。普通工厂战禁捕捉仍不变，初遇和派遣获得都不自动加入工厂租借池。未来新增赠予另行定稿。Seen 精确展示时机和 Forms 粒度未定，不借本次任务重设它们。

### F4 移除生蛋功能承诺

基地不再显示“培育/生蛋/孵化”入口或蛋数量、可领蛋等占位提示，中文和英文一致；移除相应已无用途的页面分发/状态占位，不创建替代模块。不删除历史开发证据，不移除无关游戏的蛋组参考数据。来源：用户取消生蛋与 designer 范围修订。

## 边界情况

- 初遇尚未确认、确认写入失败、确认后刷新、重复进入图鉴和同版导入不得引入候选全集 Owned。
- 初遇所属世代与设置池不同仍不混进租借；初遇物种恰好被租借时数量也不重复。
- 工厂进化、换怪、继续组、失败、退出不隐式修改永久所有权。
- 旧档无可靠来源时宁可按明确版本提示处理，不猜测旧 Owned 的永久来源；保留用户导出机会遵循既有损坏/旧档流程。

## 验收条件

- AC1 新档确认前 Owned 未被六候选污染；选定伙伴确认后只有该物种永久登记，刷新及同版导入保持。
- AC2 自然六选三与真实首战不增加 Owned；受控战次 UI 换怪、租借进化后仍不增加，Seen 有对应记录。
- AC3 图鉴筛选/数量、基地显示与存档一致；重复进入不增长，初遇不进入工厂队。
- AC4 中文/英文基地不再出现生蛋相关占位，390×844、320×568、844×390可读可点；设置及原有入口可用。
- AC5 实现者与独立 auditor 四项静态门禁，覆盖全部 Owned 写入口、初遇持久化及旧档行为；player 用最终固定代码、真实 Go+Vite 取证，不用旧截图证明新版本。
- AC6 真实 UI 完成现有派遣加入及事件战成功捕捉后，永久记录与图鉴增加并在离开事件、开始工厂、刷新/重开/同版导入后保留；失败/取消不登记，重复处理同一次结果不重发。可使用明确标注的受控就绪派遣/捕捉概率夹具，但须实际走事件与捕捉路径。
