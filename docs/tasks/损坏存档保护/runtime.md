# 损坏存档保护运行验收

2026-09-26，在 auditor 安全修复后的稳定工作树上，用独立 Chrome 移动模拟来源 `127.0.0.70`—`.76` 验收，未读写用户 `127.0.0.1` 存档。以同版本真实第 21 胜 `READY/BASE` 可续挑战存档为模板，仅在测试隔离源构造损坏原文。390×844 为主，非法 stage 与空字符串还用 844×390。此前热更新期间的首轮样本不作为最终结论；以下六样本运行时未捕获 HMR 或页面错误。

| 隔离样本 | 页面分类 | 备份格式 | 原文与下载 | 等待／后台／刷新 |
| --- | --- | --- | --- | --- |
| `READY` 敌队缺失 | 存档无法读取 | JSON | 逐字符一致 | 原文保持 |
| `READY` 阶段为 0 | 存档无法读取 | JSON | 逐字符一致 | 原文保持 |
| `challengePaused=true` 但快照不是 BASE | 存档无法读取 | JSON | 逐字符一致 | 原文保持 |
| JSON 截断 | 存档无法读取 | TXT | 逐字符一致 | 原文保持 |
| 空字符串原文 | 存档无法读取 | TXT，0 字节 | 逐字符一致 | 原文保持 |
| 旧 v8 | 旧规则存档不兼容 | JSON | 逐字符一致 | 原文保持 |

每例均在初始化后比较原始 `localStorage`，下载原文，与下载文件逐字符比较，再点击“清除并重新开始”进入二次确认、取消、触发页面隐藏和退出事件、切到另一浏览器标签、刷新；六例所有比对均相等。取消后键盘焦点返回“清除并重新开始”。[六样本逐步状态和 SHA-256](evidence/corrupt-save-postfix-results.json)。[390×844 损坏提示](evidence/missing_team-postfix-screen.png)与[844×390 非法阶段提示](evidence/bad_stage-postfix-screen.png)的文字和按钮可读可点，未见横向溢出。缺队伍样本在确认清除后进入新档，原损坏文本不再保留；其余样本只取消，未清除。

另在独立有效第 21 胜存档的设置页导入损坏 READY、截断 JSON、空文本，均反馈“导入文件损坏，原有存档未修改”，导入前后原本有效存档字符串相同；导入 v8 则提示旧规则不兼容，原档同样不变。[导入状态](evidence/import-postfix-results.json)。实体手机的下载管理器与后台行为尚未覆盖，本次为 Chrome 移动模拟。
