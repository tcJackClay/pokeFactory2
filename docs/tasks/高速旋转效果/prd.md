# PRD：高速旋转的自身效果

orchestrator 拥有。缺陷来自自然长局基线的真实出招，参考为本目录 design.md 固定 Rogue 普通源；无需新增玩法决定。先写技术/验证方案，实施在永久收藏和九道具整合后串行进行，禁止同时修改控制器、通用副效果或 move builder。

## Feature Spec

1. 高速旋转仍攻击对手。有效命中后提高使用者速度1级，目标速度不因此改变；日志、实际等级及后续行动顺序一致。固定一般/物理/50威力/100命中/40PP，当前单纯、唱反调与等级上下限按统一规则处理。
2. 同一次有效攻击解除使用者已有持续束缚、寄生及其关联状态，清空本侧隐形岩和全部毒菱层数。速度已+6仍清除，无可清项目仍提速。不清对侧、普通中毒或扎根等无关效果；不增加尚未实现的其他陷阱系统。
3. 落空、保护、实际属性免疫或无法行动不触发提速/清除。击中替身（含打破）或击倒目标（含末只）仍执行合法自身效果，按照固定源在倒下/结算前完成；不能误写给下一只成员或先退出战斗漏掉效果。
4. 若修复共享伤害自强化解析，按语义区分攻击目标与受益者。保留概率、主次效果、强行适用性和既有override，不把所有正数变化归自身，也不把所有自身效果视为不可抑制主效果。蓄能焰袭/增强拳/充电光束及虚张声势/吹捧的代表回归以design第5节为准，不扩成全招式重写。
5. 双方路径一致，每次出招一次PP、一次行动和一次清理/提速；已合入轮次、当前天气/场地、持有物和永久收藏契约保持。完整回合存档及刷新保留正确等级与陷阱状态，下一战仍按工厂规则恢复。

## Edge Cases 与验收

- 原自然缺陷输入必须经真实生产builder再构造，不能由夹具手动补appliesTo来证明修复。将103→104的旧证据保留为失败历史，修复版单独取证。
- 静态覆盖双方、正常/满等级、保护/落空/免疫、替身存续/破裂、击倒/末只倒下、同时全部清除/无项目/仅对侧有项目、概率自身强化与对敌强化反例。
- 真实Go+Vite冻结最终代码，受控场景完成上述主要玩家路径，并补自然短链；无需为强求抽到同招反复重开刷结果，自然抽取未覆盖时诚实列缺口。主390×844并复核320×568与844×390关键日志。
- 独立auditor四门禁后player实玩。前版本自然败退不用于推断修复后胜负；该任务通过不等于自然七战、全部招式效果或实体手机通过。

详细状态时序与验证方案归architect；未实现撒菱/黏网/钢阵记录为覆盖边界，不在此PRD新增系统。
