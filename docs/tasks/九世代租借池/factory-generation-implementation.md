# 单世代隔离同步切片

新增 `-factory-generation=1..9`。它从指定世代的工厂索引候选和同世代固定参考 set 取 `pokemon` 与固定招式种子，复用现有仅由 `pokemon` 正向发现物种、全部特性及招式的有限闭包。禁用物种 201 不进入种子。默认 `-factory` 仍取九代全集；`-factory-generation` 与 `-full`、`-factory-sample` 互斥。

单世代模式仅向已校验的隔离 `-state` 准备 PokeAPI 版本，不同步基础清单或 CSV，不写活动指针。默认限制为 3000 键、512 MiB、30 分钟、2 worker；可用原有上限参数进一步收紧。`-state` 指向共享 `var` 或其别名会被拒绝。

纯测试逐代核对当前种子数：1–9 代分别为 368、271、332、116、161、79、93、95、143；验证跨世代排除、禁用物种、九代特殊形态及非法参数。现有本地假上游同步测试仍验证正向闭包、上限、失败清理和不激活。本轮仅运行本地测试，没有对任一世代发起真实同步。
