# 派遣物品结果赠球与阿罗拉岩石入口

日期：2026-10-14。来源：`docs/tasks/局外规则提案/球来源提案.md` 的 B + Q1，经用户本轮明确批准。本文是玩法设计与验收口径，**尚未实施或运行验收**。实施顺序按用户决定：先完成九种持有道具与手机界面的实玩验收并合入 `dev`，然后实施本任务。

## 用户已定

1. 用户原话：**「现有派遣的物品结果额外给普通球 3 颗，免费、每次结果只领一次」**。每次现有派遣完成并得到 `item` 结果，原成长道具与原训练收益照常发放，再免费给 3 颗普通球。同一个已确定结果只可领取一次；另一次派遣若再次得到 `item` 结果，仍可再领。本规则不创建每日额度、第一次赠球或第几次必得的保底。
2. 用户原话：**「阿罗拉增加岩石属性资格，保留现有 10 小时派遣（推荐）」**。阿罗拉现有 `requiredTypes` 为妖精、幽灵、草，增列岩石；已正式拥有的岩狗狗以及其他符合岩石资格的永久收藏可派遣。现有 10 小时派遣、地区物种池及结果概率保持；其他地区不变。
3. 用户确认的共同边界：**球永久保存在基地，普通工厂仍禁捕捉**。获得的球跨工厂挑战、胜负、基地返回和同版存档保留。工厂租借队、工厂临时背包及第 3/6 胜交换商店不成为本次球来源或使用入口；已有地区派遣加入和可捕捉事件战斗沿原规则耗球。永久收藏不进入普通工厂租借队。

## 验收结果

- 从只拥有岩狗狗的新档自然选择阿罗拉，资格可通过；显示及计时仍为 10 小时，其他八地区资格、阿罗拉物种池与结果概率配置不变。派遣不可用 DEV 加球或改档来代替此自然入口证据。
- 物品结果一次领取后原成长道具、训练收益及 3 颗普通球同时可见；再次点击、刷新、关闭重开、同版导入不重发。另一次真实派遣再次得到物品结果可再获得 3 颗。`join` 或 `battle` 结果不附赠球，原概率、失败与取消处理保持。
- 基地库存与合法局外耗球保持一致；开始、继续、结束普通工厂后库存不减少，普通工厂不能投球。加入耗球、事件投球失败耗球与成功捕捉分别按现有规则核对；不能把 3 颗球宣传为 3 只必得收藏。
- 受控结果可核发放/幂等/存储边界，自然派遣样本核可达性；手机模拟视口与实体手机分别记录证据，静态检查不等于浏览器实玩。写盘失败后可重试且不重复领取，存档导出导入的库存与领取记录一致。
