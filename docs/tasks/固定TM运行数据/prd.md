# PRD：固定 TM 运行数据与学习资格

orchestrator 产品切片。来源：用户指定 `Pokabbie/pokeemerald-rogue` expansion 技能配置；`docs/公开版规则定稿.md` TM条、`docs/tasks/工厂内容准入/design.md`、`docs/tasks/单线工厂奖励/rogue-tm-reference.md`。

## 约束

- 工作树 `D:/Games/pokeFactory2-worktrees/fixed-tm-data`，分支 `codex/fixed-tm-data`。这是 Stage 5 可提前并行的固定数据任务。
- 本任务仅负责固定 TM 名单、项目身份、运行可读取的学习资格与准入状态；不改战斗控制器、存档结构、商店交易或页面。与状态命中/永久收藏任务文件不能重叠。
- 不把已有代码或历史截图变成通过，不激活未验收TM，不决定价格。所有50项保留在台账中，不自行删掉难做的效果。

## 功能规格

### F1 固定来源与物种口径

固定 Rogue expansion 提交 `a6adfcf18d7eaf99c2803e4b0bc04eca7af2f014` 的 `src/data/party_menu.h` 50项TM；兼容性依据其 `CanSpeciesLearnTM`，招式出现在该物种普通 profile 的 TutorMoves 或 LevelUpMoves 即符合该来源资格。动态TR不算，工厂设置世代只决定物种池，不改变TM学习规则。来源路径、版本、提取命令和可重复核对摘要保存在项目中。

### F2 正确身份与资格

运行消费者能取得50项完整名单、已核对的项目招式ID及指定物种/形态的固定来源学习资格。沿既有身份映射研究核对1025基础物种与51具名形态，不以PokeAPI全部招式随机抽取替代。物种/形态缺失或无法可靠映射时明确返回不具备已证实资格及诊断，不能默认套基础形态或全部可学；别名/特殊形态规则必须可追溯，不发明物种对应关系。

### F3 可学不等于可售

固定来源允许学习只是四项门槛之一：项目招式ID、固定正文、战斗效果验收、当前队伍至少一员可学且未学均齐全，价格获批后才可上架。本任务提供可独立测试的队员资格查询，区分已学/不兼容/身份未知；不把物种资格当作整个上架条件。准入状态默认保持未准入，当前0/50；未来准入要有对应证据位置。没有验收/价格不得作为商店候选。

### F4 数据可用性

已确定的固定学习数据可供运行加载，不依赖用户设备或仓库output中的临时提取文件，也不在运行中回源GitHub研究库。保留独立参考元信息，便于未来更新时发现源版本或映射变化；不把参考未实现效果静默降级成其他招式。大小与加载方式由architect提出，不能拖慢现有首屏或额外触发全量网络查询。

## 边界与验收

- AC1 编号01–50无缺漏/重复，来源提交与文件摘要可验证，提取/生成可重复且差异可追踪。
- AC2 真实正例和反例、普通profile vs排除的变体、别名/具名形态、未知ID均按固定源判定，记录覆盖率和缺口。
- AC3 当前成员已学的TM不可再次列为新学习候选；尚未准入或未定价始终不能由本任务自动上架。
- AC4 产品运行代码消费的资源不是output临时路径；构建成功，数据读取可离线确定，不新增首屏请求。
- AC5 四项静态门禁与独立auditor通过；记录这是数据/静态证据，玩家实际购买学习与50招效果仍待后续实玩，不能宣称本任务带来50项准入。
