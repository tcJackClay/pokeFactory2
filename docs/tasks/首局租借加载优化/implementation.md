# 首局租借加载优化实施记录

本轮先解除无限等待。工厂物种索引请求限时 4 秒；单个宝可梦资料请求每次限时 6 秒，同一资源的重试合计限时约 8 秒；整次六卡生成限时 30 秒。这些期限覆盖响应体解析。超时会取消物理请求；即使某个请求不响应取消，外层等待也会按时结束。

初租借必须先取得工厂索引，避免索引故障后逐候选回源。预取和点击共用同一次生成；失败时不在同一次点击中隐式重跑。基地显示可重试错误，主按钮改为“重试载入”。超时或切换世代后，旧生成结果不能提交。租借加工要求完整特性与招式资料，资料缺失时报错，不以默认招式掩盖。未改变候选池、抽样顺序、随机调用、持有物或战斗数值。

结束当前连胜时也清除本轮已使用训练家集合，防止下一局继承。

验证：定向超时/取消/重试测试通过；全套 123 项测试、类型检查和生产构建通过。第一世代与第九代的真实浏览器耗时、请求数、失败路径及手机触控仍待 player 记录，性能目标尚未验收。

第二轮仅优化租借的完整资料路径：先完成原有招式随机排序，再并发读取排在前面的四个招式；参考 set 的固定招式也并发读取。结果仍按原先顺序组装，六只成员继续顺序生成，非完整资料路径仍按原逻辑运行。缺资料仍使租借失败。测试用逆序完成的四个请求验证结果对象与顺序不变，并验证任一招式失败不会返回部分结果。合并后类型检查、127 项测试和生产构建通过；浏览器耗时与请求数需重新测量。

第三轮移除 BASE/START 进入 600 毫秒后的图鉴目录、属性、15 个快照和 20 个招式自动预载。CollectionScreen 打开时本来就会按需读取目录与属性，再按已见条目读取快照和当前条目招式；事件页选择器也按需读取已拥有宝可梦快照。租借生成仍自行读取工厂物种索引。敌队预取与随机过程未改，方便浏览器分别归因首局请求数和可操作时间。

第三轮静态验证：类型检查、127 项测试及生产构建通过。首次打开图鉴、事件推荐/选择和冷档六卡请求数仍待浏览器复验。

图鉴首次打开时发现招式详情的中文名要等待大量招式详情请求之后才会读到 CSV 回退表，等待期间画面显示英文标识。现在图鉴详情独立并行读取已有 CSV 名称表；中文界面依次取招式详情中文名、CSV 中文名、英文名，英文界面取英文名。招式类型、威力、学习列表及资料获取路径未改。新增中文、英文、缺译回退及 CSV 读取测试；类型检查、130 项测试和生产构建通过。运行画面仍待 player 复测。
