独立故障样本在点击前将 `/api/**` 请求注入 503。2.13 秒后返回基地，显示「租借资料加载失败或超时，请检查连接后重试」及「重试载入」按钮，存档仍是 `EMPTY`、0 BP。撤销故障后点重试，11.94 秒显示六卡。[错误画面](../暂停挑战跨页恢复/evidence/v10-rental-error.png)、[重试成功画面](../暂停挑战跨页恢复/evidence/v10-rental-after-retry.png)、[操作与状态](../暂停挑战跨页恢复/evidence/v10-rental-error-retry.json)。此故障是浏览器路由人工注入的 503；它验证明确反馈和一次恢复重试，不能覆盖请求自然超时、连接中断后空缓存以及连续失败的全部情况。

两代首次可玩均从此前超过 120 秒等待缩短到约 14 秒，六选三和第 1 战可达。实施计划提出的第九代冷启动三次中位数 ≤6 秒、最慢 ≤10 秒及 JSON 请求数 ≤80 尚未通过：本次单次点击耗时 14.31 秒，且请求类型未拆分；也没有三次同条件测量。公开发布前需完成同等网络条件的重复计时和性能优化。本轮仅模拟手机视口，未在真实手机触控设备上验收。
