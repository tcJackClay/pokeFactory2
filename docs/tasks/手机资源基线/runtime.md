## 试运行异常与待查线索

1. 初版 harness 沿用旧脚本将 `battleResume.turn` 当数字，但它实际是 `PLAYER/ENEMY`。此脚本错误已改为日志变化且面板恢复可操作；`evidence/discarded-harness-trial/` 仅保存当时截图，不计入正式基线。
2. 第二版等待 PP 下降，漏处理初始 `currentPp` 可缺省而回退 `pp` 的状态，造成超时；最终 harness 用日志与 UI 判定，摘要记录 `currentPp ?? maxPp ?? pp`。`discarded-pp-probe/` 保留试验原件，不能把该超时本身当游戏失败。
3. 该试验另有值得战斗模块定向检查的真实画面：电海燕使用飞翔、对手走鲸 HP 降至70%，随后对手未命中，画面飞翔仍 PP15/15。原件 `discarded-pp-probe/run-1/failure.png` 和 `result.json`。正式三个不同自然样本 PP 均正确下降，所以**这是特定路径疑点，不是“全部 PP 不消耗”的结论**；尚未在固定条件复现，也未修改实现。
