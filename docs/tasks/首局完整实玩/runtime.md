三视口当时可见图片均已加载，`img.complete=true` 且 `naturalWidth>0`。主样本无页面异常、控制台错误、HTTP 400 及以上响应或 Vite 热更新。横屏战斗画面同时露出 `protect_chain`、`uproar` 两个原始机制 ID；这是玩家可见的本地化缺陷，已单列修复任务，不能把“无控制台错误”理解成文案验收通过。前两次自动化尝试误用“换人”“对战”作为按钮文字，实际 UI 为“出战”“战斗”；这属于测试脚本定位错误，未作为游戏失败样本。列表首次截图也拍在切换动画期间，补测等待列表稳定后取证。

本次只测第一战的一次主动换人和一次真实招式操作，未打完整场胜负；“吵闹”未造成伤害，伤害数值与击倒结算不在本轮通过范围。视口切换是桌面 Chrome 手机模拟，实体手机的浏览器栏变化、旋转和手指误触尚未验收。
