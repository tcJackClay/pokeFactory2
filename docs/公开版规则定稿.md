用户另已决定：本轮所有修改**不要求兼容过往存档**。旧存档可重置或拒绝导入，但玩家必须在清除或拒绝前得到明确提示；旧版逐场代币不得转换为新 BP。当前版本形成的新存档仍须通过刷新、重开和同版本导出导入保持正确。

`手机竖屏属性角标/runtime.md` 已在 320×568 Chromium 模拟手机视口从新档进入首战、看见四招属性角标并实际点按一招；这是窄屏局部实玩，不是实体手机或完整长局验收。戏法空间切换、叶暴风/流星群自降及回合末濒死续接已合主线并有静态验证。`单线工厂奖励/snow-tailwind-browser-runtime.md` 在隔离测试存档注入招式和数值后真实 UI 施放雪景与顺风，记录雪状态、无额外雪伤及冰系物理受伤对照；顺风行动顺序与四回合计时仅为观察值，敌方先手双动及回合末竞态修复后须复测，单次伤害对照也不能精确证明倍率。`单线工厂奖励/toxic-spikes-browser-runtime.md` 用注入的双方招式与队伍，真实 UI 观察到两侧两层毒菱、入场剧毒、己方毒属性吸收和刷新保持；另在边界补测发现敌方一次行动可重复铺层，一层预置后的普通中毒、第三次施放失败与飞行免疫已单独验证，回合流程须修复后复测；原横屏状态文案曾截断，主线 `7693a22` 修复后在独立 390×844、844×390 样本中复验完整可读及横屏返回战斗，修复后样本只复测文字布局。`单线工厂奖励/stealth-rock-runtime.md` 另在隔离手机模拟视口以注入的玩家侧隐形岩与两只 1 HP 后备，通过真实 UI 换人验证连续入场倒下、连续补位及恢复操作；没有验证敌方侧、自然施放、精确伤害倍率或实体手机。`单线工厂奖励/opponent-prefetch-browser-runtime.md` 以隔离浏览器测试 404 验得敌队预取失败提示、进度保留和恢复后的下一战重试；真实弱网、基地继续节点和实体手机仍待验。奖励事务仍在隔离工作树，四卡生成、商品规则及奖励装备返还的完整浏览器验收仍未完成；TM 仍无任何发布准入项。
