| 整组七战获胜后才发放 Battle Points；败退 0 BP | 用户最新决定覆盖此前“每场胜负立即入钱包”；数值与条件按本地参考实现的**工厂单打**表 | 前六战胜利只推进挑战，钱包 BP 不增加；第七战胜利完成整组后入账。第 1、2 组各 3 BP，之后按 `sBattlePointAwards[FRONTIER_FACILITY_FACTORY][FRONTIER_MODE_SINGLES]`；实际击败工厂首领额外 10 BP；中途败退 0 BP，余额上限 9999。 | `跨组首领结算/runtime.md` 已在同一隔离存档用开发辅助推进 21 胜：前三组累计 3、6、20 BP，第 21 战 Noland 基础 4 + 首领额外 10；第 22 战败退 +0，余额保留。后续组数与完整自然连胜仍待验。 | 基地商品待定。 |
| 首版单线工厂：每组第 3、6 胜后四选一；每胜 +1 本局补给券 | 用户最新决定覆盖此前“Classic 胜后无奖励卡”和双模式首发设想；参考实现没有本项目奖励卡或补给券 | 每组第 3、6 胜后先可选换怪或跳过，再从四张卡中领取一张；卡加载失败留节点重试。首版卡仅战斗相关道具与招式机，**其中五件持有物已定稿**；不开放回复类道具、新宝可梦、进化、扩容，也不重抽。每胜得 1 张补给券，跨七战组保留至整次挑战结束；券与基地 BP 分开。首版无 Classic/Rogue 模式选择。 | 当前代码的单线主流程仍跳过奖励卡；每胜 +1 本局券已实现并通过静态门禁、运行验收待完成；`factoryRewards.ts` 旧触发配置是第 4、7 战前，`RewardScreen.tsx` 重抽仍扣基地 BP，必须禁用该路径；`shopItems` 尚未形成可用局内兑换。旧“无奖励卡”浏览器记录仅证明旧版本。 | 其他战斗道具和 TM 名单、统一 TM 数据口径、补给商品/价格/限购/兑换入口待定；见 `docs/tasks/单线工厂奖励/design.md`。 |
| 战后状态与持有物 | 用户明确工厂战后自动回复状态，无需回复类奖励道具；最新明确持有物在下一场战斗前返还 | 战果成立后恢复队伍 HP、PP、异常及临时战斗状态；结果和换怪页保留本场消耗或被拍落后的当前持有物。确定下一场参战队伍后、开战前，返还各成员的本局持有物基准：初始为租借原配，选中持有物奖励后改为奖励装备；第七胜后没有下一战时不提前返还。 | 战后状态恢复已合入并通过静态门禁；租借原配记录、下一战前返还与落盘已实现并通过静态门禁；奖励替换基准尚未实现，可消耗持有物的真实手机战斗尚未验收。见 `docs/tasks/战后恢复/held-item-plan.md`。 | 奖励卡的战斗道具具体名单仍待定。 |
| 奖励持有物装备与替换 | 用户最新决定；参考工厂固定租借队有原配持有物，奖励卡装备是本项目扩展 | 首版持有物奖励池确定为焦点镜 `scope_lens`、先制之爪 `quick_claw`、王者之证 `kings_rock`、讲究头带 `choice_band`、气势头带 `focus_band`。选卡后选择租借队员装备；已有持有物时确认替换，旧物不进背包。新物成为该成员**本次挑战以后每场战斗开战前**的返还基准；战斗中被消耗或拍落，下一战仍返还新物。 | 现有 `useRewardFlow.ts` 把 ITEM 直接放入背包，尚无选成员装备/替换；`prepareFactoryPartyForBattle` 可按 `factoryOriginalHeldItemId` 返还，实施时须更新该基准和保存状态。 | 同队同名物品规则与四卡配比仍待定；见 `docs/tasks/单线工厂奖励/design.md`。 |
| TM 学习口径与工厂世代设置 | 用户最新决定 | 设置世代只控制可进入租借和敌队的物种池；奖励卡 TM 依据一套统一学习规则，不随所选物种世代切换。用户指定 `Pokabbie/pokeemerald-rogue` 的 `expansion` 分支技能配置作为参考。 | 现有 `getLearnableMoves` 未筛 machine 学习方式或版本，不能直接把所有可学招式称为 TM；指定分支的实际数据与适用范围正在核对。 | 核对该分支后确认具体 TM 名单及物种学习资格；不预设历代 machine 并集或朱紫口径。 |
| 九个世代是九个互斥池，在设置中单选 | 用户在 2026-09-26 明确指定入口和单选规则 | 玩家只选第一至第九世代中的一个；默认第一世代。开始新挑战直接使用已保存的单一池，不重复选择；有进行中挑战时锁定修改，结束后调整才对下一局生效。 | 设置页已提供九选一，当前 v11 存档只保留单一池；九代各六只租借和首战敌队已在模拟手机视口验收。 | 原型固定 Frontier set 不能覆盖九个独立世代池；现有跨世代随机机制属于 PokeFactory2 扩展，不能据此声称 Classic 固定池已对齐。 |
| 首发初遇伙伴从固定六只中选一只 | 用户在 2026-09-26 本轮定稿；完整物种及资源核对见 `docs/tasks/初遇伙伴/design.md` | 初遇同时展示 25 皮卡丘、133 伊布、175 波克比、447 利欧路、744 岩狗狗、921 布拨；确认前可改选，确认后绑定当前存档。伙伴仅在基地陪伴，不进入工厂租借队；六只候选与设置中的工厂世代池相互独立。 | 当前 v11 已实现选择及存档绑定；`初遇伙伴/runtime.md` 在六个独立新档和三个手机模拟视口验过显示、刷新、同版导入、写入失败重试及租借池独立。 | 亲密度数值、增长方式与额外剧情未定，不从本条推导。 |

用户另已决定：本轮所有修改**不要求兼容过往存档**。旧存档可重置或拒绝导入，但玩家必须在清除或拒绝前得到明确提示；旧版逐场代币不得转换为新 BP。当前版本形成的新存档仍须通过刷新、重开和同版本导出导入保持正确。
